## Correção: erro do PixGG mais claro

- Quando o PixGG recusa a conexão, o cartão **Doações** agora mostra o código HTTP e o texto que o PixGG devolveu. Antes aparecia só "O PixGG recusou o Client ID/Client Secret", o que não diferenciava credencial errada de permissão da aplicação ou de bloqueio do site.
  - **HTTP 401:** Client ID ou Client Secret errados.
  - **HTTP 403:** acesso negado. Confira se a aplicação está ativa e se o Client Secret é o mais recente (gerar um novo invalida o anterior).
- As chamadas ao PixGG agora se identificam (`User-Agent`), como pedem alguns firewalls de sites.
