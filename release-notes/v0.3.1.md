## PixGG: funciona mesmo quando a API recusa o cadastro automático

Em algumas contas, a API do PixGG responde `403 {"message":"Forbidden"}` quando o app tenta cadastrar sozinho a URL de webhook. Antes, o app parava com "O PixGG recusou o Client ID/Client Secret".

Agora o app **continua escutando** e mostra no cartão **Doações → PixGG** a URL de webhook com um botão **Copiar**. Para usar:

1. Clique em **Copiar**.
2. Em pixgg.com → **Aplicações**, abra a sua aplicação e cole a URL no campo de webhook.
3. Salve. Pronto: as doações pagas chegam ao app em até ~3 segundos.

A URL depende do Client Secret. Se você gerar um secret novo, conecte de novo no app e cole a URL nova no PixGG.

## Outras mudanças

- Os erros do PixGG agora mostram o código HTTP e o texto que o PixGG devolveu.
- As chamadas ao PixGG passam a se identificar (`User-Agent`).
