Primeira versão para download do **Keybinds Redemptions**: um app para Windows que aperta uma tecla no PC do streamer quando acontece algo na live.

## Baixar

- **`Keybinds Redemptions-Setup-0.2.0.exe`**: instalador.
- **`Keybinds Redemptions-Portable-0.2.0.exe`**: roda sem instalar.

O executável não tem assinatura digital, então o Windows SmartScreen avisa na primeira vez: clique em **Mais informações → Executar assim mesmo**.

## O que o app faz

- **Uma regra liga um evento da live a uma tecla ou combinação** (ex.: Ctrl+G). Os eventos são:
  - **Recompensa** de pontos do canal.
  - **Bits**: a partir de X bits e, se quiser, até Y.
  - **Sub**: nova ou renovada, de qualquer tier ou de um tier específico.
  - **Gift sub**: a partir de X subs dadas de presente de uma vez.
  - **Doação** em dinheiro, por faixa de valor, de um serviço específico ou de qualquer um.
- **Faixas não se somam:** se mais de uma regra servir para o mesmo evento, vale a de maior valor mínimo. Com R$ 5+ e R$ 10+, uma doação de R$ 12 aperta só a de R$ 10+.
- **Serviços de doação:** StreamElements, Streamlabs, LivePix e PixGG, conectados pelo cartão **Doações**. Os tokens ficam cifrados no PC.
- **Tecla de verdade:** a tecla é enviada como scancode, então funciona também em jogos que ignoram tecla simulada comum.
- **Ajustes por regra:** quanto tempo segurar a tecla, quantas vezes repetir e o intervalo entre as repetições. O botão **Testar** espera 3 segundos e aperta.
- **Sem atropelo:** os eventos entram numa fila e rodam um de cada vez.
- **Controles da live:**
  - **Pausar**: os eventos continuam aparecendo na atividade, mas nenhuma tecla é apertada.
  - **Parar tudo**: interrompe a ação em andamento, esvazia a fila e solta na hora qualquer tecla presa.
- **Bandeja:** fechar a janela deixa o app rodando perto do relógio, e dá para abrir junto com o Windows.

## Primeira configuração

1. Crie um app em [dev.twitch.tv/console/apps](https://dev.twitch.tv/console/apps/create) com **Client Type: Public** e copie o **Client ID**.
2. No app, cole o Client ID e clique em **Entrar com a Twitch**.
3. Para doações, conecte o serviço no cartão **Doações**. O README explica onde achar cada token.
4. Crie as regras e use **Testar** com o jogo aberto.

## Antes de usar ao vivo

- Faça **uma doação de teste em cada serviço**. As integrações foram testadas só com servidores simulados, não com contas reais.
- **LivePix:** confira se o valor aparece certo na atividade. O app supõe que a LivePix manda o valor em centavos.
- **PixGG:** as doações passam pelo asrus.app, que precisa estar configurado. Use uma aplicação do PixGG só para este app, porque ele troca a URL de webhook dela.
- **Jogo como administrador:** o Windows bloqueia a tecla. Abra o app como administrador também.
